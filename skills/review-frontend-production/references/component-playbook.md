## 执行约定

- 先定位当前页面的实际 UI 单元，再读取对应 C 编号；不要把本文件一次性变成项目必做功能清单。
- 将每项拆成状态、动作与反向中断、语义键盘、数据布局、验收、修复六个维度；逐项记录适用性。
- 按控件已承诺的能力检查状态。仅在存在异步、权限、远程数据、多选、可编辑等能力时检查相应条件项；未实现且未承诺的能力记为不适用，说明原因。
- 在支持悬停的指针设备检查 hover；在触摸设备检查可直接发现的操作入口，不要求模拟永久 hover。
- 对正常、空白、异常、只读、禁用等状态复用设计系统，但检查状态组合：例如“只读且有错误”“加载且保留旧值”“失权且有未保存内容”。
- 把下面的验收步骤当作待执行方案。仅在真实工具、页面和测试数据可用时执行；没有执行证据时标为未验证。
- 优先使用项目现有组件、测试设施和公开 API。不要因本手册出现某种模式，就迁移框架、引入新库或扩大业务范围。
- 对涉及外部写入、计费、删除的步骤沿用会话授权范围；必要时使用隔离测试数据或受控替身，并明确替身无法证明生产后端行为。
- 记录浏览器、视口、输入方式、用户角色、数据样本、前置状态、操作步骤和实际结果；把截图、DOM 观察、请求记录或测试日志关联到实例。
- 将静态代码发现、实际复现、待验证风险和不适用分开记录；不要把工具没有报警写成全项通过。

## 共享定义与页面实例

| 层级 | 建立记录 | 检查内容 | 限定结论 |
|---|---|---|---|
| 共享定义 | 记录组件名称、来源文件、版本、变体、公开属性与内部状态 | 检查原生语义、受控契约、事件顺序、默认样式、基础键盘行为 | 只证明指定定义和被测变体的契约 |
| 页面实例 | 记录路由、区域、业务实体、实例标识、标签、属性、权限和覆盖样式 | 检查真实数据、回调、禁用条件、ID 唯一性、弹层容器、响应式布局 | 只证明指定页面实例在被测条件下成立 |
| 组合流程 | 记录上游输入、下游动作、后端状态、导航与回退路径 | 检查跨控件焦点、状态传递、提交失败、取消、刷新和恢复 | 只证明被覆盖的组合与端到端路径 |

- 建立共享定义到页面实例的一对多映射；即使多个实例使用同一 Button，也记录每个实例的动作和条件。
- 按每个页面实例查找差异：覆盖 CSS、插槽、事件冒泡、缺失名称、父级 form、禁用权限、局部数据、层叠上下文。
- 在重复项目中先清点动态实例集合，再覆盖不同内容和状态类；不要把相同行数的机械点击当成有价值的完整性证明。
- 对修复共享定义的改动列出所有受影响路由；复查每类不同用法及高风险实例，不只复跑组件库故事。
- 对父层遮挡、错误数据映射、错误回调等实例缺陷，优先修复调用处；不要无证据改变共享组件契约。
- 输出覆盖时使用“已验证 8 个实例中的 6 个，其余 2 个缺少权限测试账户”等可核对表述；禁止写“组件库通过，所以所有页面通过”。

## 组件索引与组合规则

| 页面特征 | 组合读取 |
|---|---|
| 设置或配置表单 | 读取 C01、C03–C09、C14、C29，并按出现的弹层读取 C10–C13 |
| 数据管理页 | 读取 C16、C18–C25、C29、C32，并检查每个行操作的 C01/C12 实例 |
| 文档工作台 | 读取 C11、C24、C26、C28、C32，并检查滚动、焦点与长会话 |
| AI 对话或训练任务 | 读取 C04、C25、C29–C32，并检查会话切换和取消的真实服务端语义 |
| 信息展示或公开页面 | 读取 C02、C16–C18、C27–C29；仅在需要搜索收录时增加 SEO 检查 |

- 对一个单元允许关联多个 C 编号，例如把“可搜索的多选筛选器”同时按 C06、C21、C22 检查。
- 对未列出的业务组件按六个维度新增实例记录，并组合现有模式；不要把未命中索引视为无需检查。

## C01 按钮与图标按钮

**适用条件：** 页面存在提交、确认、切换、重试、危险操作或图标触发器时执行。

- **状态：** 覆盖默认、焦点、按下、禁用；在异步动作中覆盖忙碌、失败可重试、成功和失去操作权限。
- **动作与反向中断：** 验证单击、双击、按住键、重复提交；在忙碌时切页或取消，检查是否多次创建任务或误执行父级动作。
- **语义键盘：** 优先使用原生 button；核对 type、可访问名称和键盘激活；区分原生 disabled 与需自行阻止执行的 aria-disabled。
- **数据布局：** 换入最长已支持文案；检查 spinner 不改变按钮宽高，图标对齐、触摸目标和忙碌标签不遮挡相邻操作。
- **验收：** 从键盘聚焦并激活；在受控慢响应下快速触发两次；核对可见反馈、真实动作次数、失败后的可再次操作状态。
- **修复：** 修正按钮语义和 form 默认提交；将忙碌状态绑定实际请求；对创建类动作与后端约定幂等，别把前端禁用当作唯一防重保证。

## C02 链接与可导航区域

**适用条件：** 页面存在内部导航、外部资源、可点击卡片或下载入口时执行。

- **状态：** 覆盖默认、焦点、当前页；在资源不存在、无权限或链接失效时检查目标行为。
- **动作与反向中断：** 验证普通打开、新标签打开、复制链接、刷新深链接、后退；检查卡片子按钮是否误触导航。
- **语义键盘：** 用带有效 href 的链接表达导航；提供可区分的链接名称；不要用 role=link 代替完整原生行为。
- **数据布局：** 检查长 URL、长标题、折行、图标标签和截断后的完整信息入口；避免嵌套交互元素。
- **验收：** 直接访问目标 URL，再前进后退；通过键盘打开；在目标资源失效时验证实际状态和返回路径。
- **修复：** 还原真实链接与路由契约；拆分卡片主导航和行内动作；仅在业务需要时添加外链、新窗口或下载说明。

## C03 单行输入

**适用条件：** 页面存在文本、密码、邮箱、标识符、数值文本或带格式输入时执行。

- **状态：** 覆盖空值、有值、聚焦、只读、禁用、无效；在异步校验中增加校验中、失效结果和接口错误。
- **动作与反向中断：** 验证输入、粘贴、清空、撤销、自动填充、光标中部修改；在校验未完成时换值或离开字段。
- **语义键盘：** 关联 label、帮助和错误；按字段目的选择类型、输入模式与自动完成；保留密码管理器和粘贴能力。
- **数据布局：** 测试中文组合输入、emoji、前后空白、超长值；对数值输入允许合法编辑中间态，不在每次键入时破坏光标。
- **验收：** 用目标输入法确认候选词，再粘贴、撤销、移动光标编辑；核对提交值、显示值、错误关联和光标位置。
- **修复：** 分离编辑文本与解析值；延迟破坏性格式化至合适时机；丢弃过期校验结果；把必须的校验同时落实到接口。

## C04 多行文本与消息输入

**适用条件：** 页面存在评论、长描述、聊天输入或自动增高输入区时执行。

- **状态：** 覆盖空白、换行、超限、草稿、发送中和失败；在支持附件时检查正文与附件的组合限制。
- **动作与反向中断：** 区分 Enter、修饰键换行和输入法选词；发送后快速继续输入、切换会话、取消发送或恢复失败草稿。
- **语义键盘：** 使用合适文本框语义和名称；明确换行与发送规则；不要拦截输入法、系统编辑及辅助技术依赖的按键。
- **数据布局：** 检查自动增高上限、内部滚动、软键盘遮挡、长行和粘贴大段文本；在存在长度限制时明确按字符、字节或 token 计算。
- **验收：** 用中文输入法按 Enter 选字，确认未误发送；在受控失败响应后核对草稿、附件和焦点；在真机打开软键盘。
- **修复：** 正确管理组合输入状态；按会话保存草稿；对发送请求使用稳定标识；避免发送成功后清空用户刚开始写的新内容。

## C05 复选框单选与开关

**适用条件：** 页面存在多选、互斥选择、布尔设置或全选控件时执行。

- **状态：** 覆盖选中、未选、禁用、只读；在全选中覆盖部分选中，在即时保存中覆盖保存中和失败回滚。
- **动作与反向中断：** 验证点击标签、键盘切换、快速连续切换；在远程失败或选项失效时检查显示与保存值。
- **语义键盘：** 优先原生控件；给组和选项明确名称；按单选组模式处理方向键；仅对支持混合状态的控件表达 mixed。
- **数据布局：** 换入长标签、说明和多行选项；检查整行点击区、相邻链接和选择命中范围是否冲突。
- **验收：** 从无选择切到部分、全部再取消；在分页或过滤后核对全选范围；在一次保存失败后检查最终服务端值。
- **修复：** 明确当前页与全量选择语义；以稳定 ID 保存选择；回滚失败的乐观状态，避免布尔值与字符串混用。

## C06 选择器与组合框

**适用条件：** 页面存在原生 select、自定义下拉、可搜索选择或多选标签时执行。

- **状态：** 覆盖关闭、展开、选中、无结果、禁用；在远程选项中覆盖加载、失败、已选项被移除和过期查询。
- **动作与反向中断：** 验证展开、选择、取消、清空和点击外部；在输入联想词后立刻换词、关闭或切页。
- **语义键盘：** 按实际模式采用 select、combobox 或 listbox；落实焦点与活动选项关联、方向键、确认和 Esc；不要把普通选项强标 menuitem。
- **数据布局：** 测试长选项、重名不同 ID、大量选项、多行标签和视口边缘；检查弹层是否被父级滚动容器裁切。
- **验收：** 仅用键盘选取并取消；让较早查询晚返回；在已选数据不在当前结果中时检查名称与提交 ID。
- **修复：** 分离输入词、活动项和已选值；绑定请求与查询；选项使用稳定身份；在真实规模需要时再评估窗口化。

## C07 数字步进与滑块

**适用条件：** 页面存在数量、区间、百分比、双滑块或可调参数时执行。

- **状态：** 覆盖最小、最大、默认、越界、空值、无效和禁用；在双滑块中覆盖端点接近和约束冲突。
- **动作与反向中断：** 验证键入、步进、长按、拖动、滚轮；在拖出边界、失去指针或取消编辑时检查值是否稳定。
- **语义键盘：** 给控件与各端点命名；按 slider 或 spinbutton 模式提供范围和值；保留键盘调整和可理解的值文本。
- **数据布局：** 检查负数、小数、单位、精度、不同地区数字格式和窄屏；别用视觉位置作为唯一值来源。
- **验收：** 输入边界值及编辑中间态，再模糊或提交；分别用键盘和指针设定同一结果；核对序列化精度。
- **修复：** 统一边界与步长规则；将显示单位和存储值分开；只在明确规则下钳制值；对精确业务计算采用约定的数值表示。

## C08 日期与时间选择

**适用条件：** 页面存在日期、时间、范围、预约或跨时区展示时执行。

- **状态：** 覆盖未选、有效、无效、禁用日期、范围起止；在跨时区或周期规则中覆盖跨日与夏令时相关边界。
- **动作与反向中断：** 验证手填、面板选取、清空、切月和取消；在修改起点、语言或时区时检查终点与草稿。
- **语义键盘：** 关联输入格式与标签；为日历实现适用的网格导航；管理日历弹层进入、关闭和返回焦点。
- **数据布局：** 检查不同月份、闰日、长月份名、12/24 小时、窄屏和错误文本；区分纯日期与绝对时间点。
- **验收：** 在已支持的两个时区查看同一测试记录；输入闰日、逆序范围与边界时间；核对接口值和展示日期。
- **修复：** 明确数据语义、业务时区和范围边界；使用区域感知格式；别把生日等纯日期无条件转成 UTC 时间戳。

## C09 表单提交与分步向导

**适用条件：** 页面组合多个字段执行保存、创建、配置或多步骤提交时执行。

- **状态：** 覆盖原始、已修改、校验失败、提交中、成功和失败；在向导中覆盖前进、返回、条件步骤和草稿恢复。
- **动作与反向中断：** 验证鼠标提交、Enter 提交、重置、取消、后退和刷新；在超时后再次提交时检查是否重复创建。
- **语义键盘：** 使用合理 form、分组、标签和错误摘要；失败后定位有意义的错误；让步骤当前位置可被感知。
- **数据布局：** 检查多个错误、服务器字段错误、跨字段限制、长提示和条件隐藏字段；核对隐藏字段是否仍被误提交。
- **验收：** 填到中途返回上一步，再使最终请求失败；确认输入保留、摘要能定位字段，且真实创建次数符合契约。
- **修复：** 建立表单与提交状态机；分离客户端提示和服务端校验；明确重复提交、脏数据离开与最终成功的判定。

## C10 模态对话框

**适用条件：** 当前交互确实要求阻断背景操作时执行；不要把所有浮层都视为模态。

- **状态：** 覆盖关闭、进入、打开、退出；在异步确认中覆盖忙碌和失败，在嵌套弹层中覆盖上层关闭。
- **动作与反向中断：** 验证触发、关闭按钮、取消、Esc 和背景点击策略；在提交中关闭、触发点消失时检查结果与焦点。
- **语义键盘：** 提供 dialog 名称和真实模态行为；进入时合理聚焦，Tab 留在模态范围，关闭后回到逻辑位置。
- **数据布局：** 检查长内容、小视口、放大文字和软键盘；保持标题、正文及必要操作可达，不让背景继续滚动干扰操作。
- **验收：** 只用键盘打开、遍历、关闭；检查背景无法被操作；删除原触发对象后验证关闭焦点仍有合理归宿。
- **修复：** 优先使用经验证的原生或现有模态机制；协调 inert、滚动锁和焦点恢复；别仅加 aria-modal 就宣称实现模态。

## C11 抽屉与侧面板

**适用条件：** 页面存在侧栏详情、配置抽屉或可并行编辑面板时执行。

- **状态：** 覆盖展开、收起、加载和失败；在编辑面板中覆盖已修改，在响应式切换中覆盖模态与非模态模式。
- **动作与反向中断：** 验证切换记录、关闭、后退、调整宽度；在保存未完成时切换目标或收起，防止结果写入错误记录。
- **语义键盘：** 根据是否阻断背景选择 dialog 或普通区域；非模态面板不要无理由困住 Tab；提供稳定标题与关闭入口。
- **数据布局：** 检查主内容剩余宽度、双滚动、固定底部操作和小屏全屏展示；保留关键字段与操作可达。
- **验收：** 在两个实体之间快速切换，再返回；缩至模式转换断点两侧；核对数据身份、焦点与未保存状态。
- **修复：** 绑定实体 ID 与加载周期；按需重置局部状态；将布局模式和交互模态分开定义，不靠 CSS 位移替代状态管理。

## C12 浮层与操作菜单

**适用条件：** 页面存在更多操作、上下文菜单、菜单按钮或非模态 popover 时执行。

- **状态：** 覆盖关闭、展开、活动项、禁用项；在异步动作中覆盖忙碌、失败和权限改变。
- **动作与反向中断：** 验证触发、外部点击、Esc、选择后关闭；检查滚动、窗口缩放和嵌套浮层不会误触背景动作。
- **语义键盘：** 区分操作 menu、导航链接集合和表单 popover；只在采用菜单模式时实现其方向键与 roving focus 约定。
- **数据布局：** 检查视口四角、长菜单项、图标与快捷键说明；观察定位、翻转、裁切、层叠上下文及滚动锚点。
- **验收：** 在表格最后一行打开菜单，再滚动并用键盘选择；核对菜单所绑定实体未变化、背景未意外执行。
- **修复：** 采用项目一致的定位和 dismiss 机制；统一顶层浮层管理；针对滚动与父容器裁切修复，不无限增加 z-index。

## C13 工具提示与帮助说明

**适用条件：** 页面存在 hover 说明、图标解释、截断文本提示或字段帮助时执行。

- **状态：** 覆盖隐藏、延迟显示、键盘显示和消失；在触摸界面中核对是否存在同等信息入口。
- **动作与反向中断：** 验证指针进入退出、焦点进入退出、Esc；在指针移入提示时检查可阅读性，避免闪烁。
- **语义键盘：** 将补充描述关联到触发元素；不要把必需标签只放在 tooltip；存在可交互内容时改用适合的浮层模式。
- **数据布局：** 检查长说明、边缘定位、放大与被遮挡情况；防止提示挡住被说明内容或相邻必要操作。
- **验收：** 不使用鼠标读取图标含义；在支持触摸的目标设备获得同等信息；确认提示不抢焦点。
- **修复：** 对必需信息使用常驻帮助；校准显示与隐藏边界；避免全站用 title 属性代替可访问帮助实现。

## C14 通知横幅与错误摘要

**适用条件：** 页面用 toast、banner、alert 或摘要反馈保存、错误、连接和系统状态时执行。

- **状态：** 覆盖信息、成功、警告、失败和已关闭；在并发事件中覆盖去重、堆叠和内容更新。
- **动作与反向中断：** 验证关闭、重试、撤销和定位错误；在超时消失、切页或重复到达时检查信息是否丢失。
- **语义键盘：** 按信息紧迫性选择状态播报；保持可操作通知的键盘入口；不要让普通成功提示强行移动焦点。
- **数据布局：** 检查长错误、多个通知、小屏与固定操作区；不要把敏感服务端详情直接作为用户通知。
- **验收：** 实际触发一次成功和一次失败；在读屏工具可用时验证播报；确认错误修复后旧错误不会覆盖新状态。
- **修复：** 以事件或任务 ID 去重；给必须处理的信息持久入口；让撤销关联真实服务端能力，别用假消失表达完成。

## C15 标签页与分段视图

**适用条件：** 页面存在互斥内容面板、分段控制或外观近似标签页的导航时执行。

- **状态：** 覆盖当前项、焦点项、禁用项、加载和错误；在内容保留时覆盖切出再返回的局部状态。
- **动作与反向中断：** 验证切换、快速往返和直接链接；在未保存面板离开或异步内容晚到时检查行为。
- **语义键盘：** 区分同页 tabs 与跨页链接；采用 tabs 时关联 tab 与 panel，并按激活模式实现方向键和确认。
- **数据布局：** 检查多标签溢出、长名称、窄屏和面板高度变化；让当前项、键盘焦点各自可辨认。
- **验收：** 用键盘切到加载较慢的标签再返回；核对当前面板、焦点、URL 和草稿规则。
- **修复：** 明确自动或手动激活；只有适合即时呈现的内容才自动激活；用稳定身份管理面板状态。

## C16 全局导航侧栏与面包屑

**适用条件：** 页面存在主导航、折叠侧栏、移动导航、面包屑或当前位置提示时执行。

- **状态：** 覆盖当前、展开、收起和权限过滤；在异步菜单中覆盖加载和失败，在小屏中覆盖抽屉模式。
- **动作与反向中断：** 验证深链接、刷新、前进后退、展开后跳转；检查导航关闭时不会遗留滚动锁或焦点陷阱。
- **语义键盘：** 使用带名称的导航区域、链接和当前位置语义；提供跳过重复导航的路径；不要将普通站点导航一律做成桌面菜单。
- **数据布局：** 检查长项目名、深层路径、多级折叠、不同权限菜单和断点切换；避免图标模式失去名称。
- **验收：** 直接进入子路由，刷新后再用键盘返回上级；在窄屏打开、导航并关闭；确认当前位置和焦点合理。
- **修复：** 统一路由元信息；独立管理侧栏展开与当前路由；服务器执行权限校验，前端负责准确表达可用入口。

## C17 折叠区与展开控件

**适用条件：** 页面存在 accordion、详情展开、更多内容或分组收起时执行。

- **状态：** 覆盖折叠、展开；在懒加载内容中覆盖加载和错误，在多项组合中检查允许同时打开的规则。
- **动作与反向中断：** 验证反复展开收起、展开后跳到内部链接；内容正在加载或内部字段报错时收起再展开。
- **语义键盘：** 用可激活按钮或适合的原生 disclosure；同步 expanded 状态；隐藏内容不得继续成为不可见的 Tab 停靠点。
- **数据布局：** 检查长标题、深层内容、动画高度和固定区域；展开后不要把当前阅读位置无理由推走。
- **验收：** 聚焦内部控件后按产品规则关闭父区；确认焦点不遗失、已填数据按约定保留，错误有可发现入口。
- **修复：** 明确卸载与隐藏的状态保留策略；校准高度变化和焦点返回；只在需要互斥时实施单项展开。

## C18 卡片列表与重复项目

**适用条件：** 页面存在列表、卡片网格、可选记录或带行内操作的重复单元时执行。

- **状态：** 覆盖空、单项、多项、选中、失效、加载和局部失败；在可编辑列表中覆盖行级忙碌。
- **动作与反向中断：** 验证添加、删除、排序、选择和打开详情；在重排后执行行操作，检查目标身份是否仍正确。
- **语义键盘：** 使用合适列表结构；给重复操作补足对象上下文；区分整卡导航、行选择和子按钮。
- **数据布局：** 测试混合高度、缺失字段、长名称、不同图片比例和大量内容；检查栅格断点与阅读顺序。
- **验收：** 让两项同名，删除其中一项并重排，再操作另一项；核对请求 ID、行级状态和焦点。
- **修复：** 使用稳定业务键；将行级状态按实体管理；针对实际密度选择列表或网格，别用数组下标维系可编辑身份。

## C19 表格与交互数据网格

**适用条件：** 页面存在表格、行选择、列排序、冻结列或单元格编辑时执行。

- **状态：** 覆盖加载、空、错误、选中、排序和缺失值；在编辑或批量动作中覆盖无效、保存中、冲突和部分成功。
- **动作与反向中断：** 验证排序、筛选、翻页、列宽与行操作；在编辑未提交时切页，在选择后改变数据范围。
- **语义键盘：** 默认使用适当 table 结构、表头关系和排序状态；仅在需要网格交互并实现完整键盘模型时使用 grid。
- **数据布局：** 测试长单元格、0 与空值、宽表、冻结列、双滚动和目标数据规模；核对格式、单位和对齐。
- **验收：** 选择行后排序翻页，再执行受控批量操作；核对真实选择范围、失败明细、键盘焦点和可见表头。
- **修复：** 固定行身份与列定义；明确服务端排序和分页契约；仅在性能证据需要时虚拟化，并补查查找、打印、读屏和焦点。

## C20 树与层级选择

**适用条件：** 页面存在文件树、组织树、层级权限或 treegrid 时执行。

- **状态：** 覆盖展开、折叠、选中、部分选中、无子项和禁用；在懒加载中覆盖加载失败及子节点改变。
- **动作与反向中断：** 验证展开、选择、移动、删除与搜索定位；在子树加载时收起、在父节点失效时继续操作。
- **语义键盘：** 按真实 tree 模式实现层级、展开、选中与键盘导航；别对普通缩进列表无条件增加复杂树语义。
- **数据布局：** 检查深层缩进、长名称、重名、循环或非法层级数据，以及窄容器中的节点和操作入口。
- **验收：** 仅用键盘展开到深层，再删除当前节点；在父级部分选中时加载新子项，核对选择策略。
- **修复：** 分离节点身份、展开集合和选择集合；明确父子传播规则；由接口保证权限与层级合法性。

## C21 搜索与联想结果

**适用条件：** 页面存在提交搜索、即时搜索、历史词或联想建议时执行。

- **状态：** 覆盖初始、输入中、查询中、有结果、无结果、失败和清空；在保留旧结果时清楚表达其过期状态。
- **动作与反向中断：** 验证输入法、连续改词、清空、提交和选中建议；让旧查询晚于新查询返回。
- **语义键盘：** 提供搜索名称与结果状态；仅在真正联想组合框中采用 combobox 模式；不在每个字符后抢走焦点。
- **数据布局：** 测试超长词、特殊字符、中文与 emoji、同名结果和高亮片段；保持搜索词与结果来源一致。
- **验收：** 连续提交 A、B 两个词并颠倒返回次序；确认最后显示 B；清空后不得被 A 的迟到响应重新填满。
- **修复：** 根据业务选择提交或防抖；绑定请求与查询版本；取消或忽略旧响应；对高亮内容采用安全文本处理。

## C22 筛选排序与条件标签

**适用条件：** 页面存在过滤面板、筛选 chip、多条件查询、重置或保存视图时执行。

- **状态：** 覆盖默认、草稿、已应用、无结果和查询失败；在可保存视图中覆盖已修改与保存冲突。
- **动作与反向中断：** 验证应用、取消、单项移除、全部重置和后退；在更改筛选时检查分页、选择范围与旧结果。
- **语义键盘：** 给每个条件和移除动作提供名称；区分用于选择的 toggle 与仅用于显示的标签；保持焦点可追踪。
- **数据布局：** 检查大量条件、长值、日期范围、窄屏换行和不同地区格式；明确空条件与“全部”的区别。
- **验收：** 应用组合条件后刷新、分享或后退，按产品承诺核对恢复；移除聚焦标签后确认焦点落点。
- **修复：** 分离草稿与生效查询；统一 URL、接口和本地状态序列化；改变数据域时显式处理分页与批量选择。

## C23 分页加载更多与无限滚动

**适用条件：** 数据规模需要分段展示，且产品存在页码、游标或追加加载时执行。

- **状态：** 覆盖第一页、中间页、末页、加载、失败、无更多；在数据总数改变时检查当前页合法性。
- **动作与反向中断：** 验证翻页、改每页数量、连续加载、刷新和后退；在请求未完成时换筛选或再次触发。
- **语义键盘：** 提供页码或加载入口名称、当前位置和追加结果提示；保留可到达底部内容的路径。
- **数据布局：** 检查不足一页、零总数、未知总数和动态行高；避免加载指示改变滚动锚点造成跳跃。
- **验收：** 在末页删除一条记录，再切换筛选并让旧加载返回；核对无重复、无遗漏和合理当前位置。
- **修复：** 按接口契约采用页码或游标；去重稳定 ID；明确追加、替换和失效策略；不要对小列表无条件引入无限滚动。

## C24 拖拽排序与分栏调整

**适用条件：** 页面存在拖放移动、排序、画布拖动或可调整分栏时执行。

- **状态：** 覆盖可拖、拖动中、有效目标、无效目标、完成和取消；在异步保存中覆盖失败恢复。
- **动作与反向中断：** 验证拖出边界、自动滚动、放到原处、Esc、指针取消及快速反向调整；检查触摸滚动冲突。
- **语义键盘：** 提供非拖拽替代操作；在可调整分隔条中落实合适的名称、范围与键盘调整；表达实际完成结果。
- **数据布局：** 检查滚动容器、缩放、横竖方向、最小面板宽度和长条目；坐标转换不要只在默认缩放成立。
- **验收：** 通过点击式替代入口完成同一移动；拖动到容器边缘后取消；核对顺序、焦点和保存结果。
- **修复：** 统一指针与取消生命周期；使用稳定 ID 和显式目标位置；约束合法范围；别将仅可鼠标操作视为完成。

## C25 上传区与附件队列

**适用条件：** 页面允许选择文件、拖入、粘贴文件、批量上传或断点上传时执行。

- **状态：** 覆盖待选、校验、排队、上传、处理、成功、失败和取消；仅在支持断点续传时检查恢复。
- **动作与反向中断：** 验证重复选同一文件、同名不同文件、移除、重试、取消和导航；在网络断开后核对队列身份。
- **语义键盘：** 保留可访问的文件选择入口、类型大小说明、队列操作和进度状态；拖入不能是唯一入口。
- **数据布局：** 检查长文件名、零字节、边界大小、扩展名与内容不一致、批量部分失败以及缺失缩略图。
- **验收：** 使用隔离样本上传一项合法、一项不合法文件；取消后重试；核对文件 ID、最终结果和正文是否仍可编辑。
- **修复：** 区分传输完成与服务端处理完成；管理预览资源释放；接口再次校验类型、大小和权限；对重试约定幂等。

## C26 富文本与代码编辑器

**适用条件：** 页面存在富文本、Markdown、代码编辑、差异视图或可编辑文档时执行。

- **状态：** 覆盖加载、空文档、有内容、只读、已修改、保存中和失败；在协作中覆盖冲突与外部更新。
- **动作与反向中断：** 验证组合输入、粘贴、撤销重做、选择复制、快捷键和切文档；在保存中关闭后检查草稿。
- **语义键盘：** 检查编辑区名称、工具栏可达性、退出编辑区的方法与辅助技术模式；不要吞掉所有 Tab 或系统快捷键。
- **数据布局：** 测试长行、超长文档、代码围栏、表格、图片失效和缩放；核对行号、选区、滚动与浮层位置。
- **验收：** 在中文输入中触发工具栏操作，再撤销；切到另一文档后让旧保存返回；核对文档身份、内容和选区。
- **修复：** 利用编辑器事务和文档模型；分离渲染内容与存储源；按需清理富文本；明确保存版本与冲突策略。

## C27 图表与数据可视化

**适用条件：** 页面使用图表、地图、仪表或可交互可视化表达数据时执行。

- **状态：** 覆盖有数据、无数据、加载、失败、选择和图例关闭；在实时更新中覆盖暂停、滞后与断线。
- **动作与反向中断：** 验证悬停、键盘或替代查询、图例、缩放和重置；在过滤或 resize 时核对选中对象。
- **语义键盘：** 提供名称、摘要及适用的数据表或可访问等价信息；不要只凭颜色或 hover 传递必要数值。
- **数据布局：** 检查零值、负值、缺失、异常值、不同量级、长标签和单位；确认轴起点与聚合没有误导含义。
- **验收：** 用包含空值、负值和极端值的可核对样本比对图中结果；缩小容器并通过非 hover 方式取得关键数据。
- **修复：** 固定数据映射与单位规则；按实际数据量选择抽样、聚合或渲染方式；明确抽样语义，避免性能优化改变结论。

## C28 图片视频与轮播

**适用条件：** 页面展示用户图片、封面、音视频、自动轮播或可放大媒体时执行。

- **状态：** 覆盖加载、成功、失败和占位；在播放器中覆盖播放、暂停、缓冲、结束及权限或格式失败。
- **动作与反向中断：** 验证播放暂停、跳转、放大、切图和关闭；在路由离开、后台或媒体失效时检查声音与资源。
- **语义键盘：** 按内容用途提供替代文本、字幕或说明；保证播放器可操作；在自动轮播中提供适用的暂停与手动入口。
- **数据布局：** 检查宽高比、裁切焦点、低分辨率、透明图、竖图、字幕遮挡和媒体尺寸预留。
- **验收：** 让一个媒体 URL 失败并切换视口；用键盘播放暂停；离开页面后确认无残留音频或不可关闭浮层。
- **修复：** 使用适当媒体语义与加载策略；对重要首屏资源安排优先级；区分装饰图与信息图，避免所有图片使用相同 alt。

## C29 加载空白错误与占位单元

**适用条件：** 任何依赖异步数据、首次使用引导或可能失败的区域均执行。

- **状态：** 区分首次加载、后台刷新、无数据、无匹配、无权限、部分失败和全局失败；不要都落到空白页。
- **动作与反向中断：** 验证重试、创建、返回、保留旧内容和离线恢复；在区域卸载后收到结果时检查状态污染。
- **语义键盘：** 给忙碌区域及状态变化适当语义；让重试与替代路径可达；不要让骨架内容成为无意义 Tab 项。
- **数据布局：** 对齐最终内容的空间与信息层级；检查错误文案长度、局部失败范围和背景刷新时的布局稳定。
- **验收：** 分别返回零条、拒绝访问、网络失败和部分数据；核对文案、可执行下一步、旧数据标签与实际请求状态。
- **修复：** 建立明确结果类型；区分请求错误和业务空集；用错误隔离保留可用区域，别用无限 spinner 掩盖终态。

## C30 AI流式消息与工具结果

**适用条件：** 页面展示逐步生成文字、工具调用、引用、富消息或多轮 AI 会话时执行。

- **状态：** 覆盖等待首段、接收中、工具运行、完整、截断、失败和取消；在支持恢复时检查重连与补发。
- **动作与反向中断：** 验证停止、重试、重新生成、复制、切会话和历史滚动；让旧流在新会话打开后继续返回。
- **语义键盘：** 给消息作者、工具状态与操作命名；控制读屏播报频率；保留用户阅读位置，避免每个 token 抢焦点或强制滚到底。
- **数据布局：** 检查未闭合 Markdown、代码、公式、长链接、大段内容和混合附件；核对复制内容与当前消息版本。
- **验收：** 用受控流拆分 UTF-8 字符和协议帧，注入断流及重复事件；切换会话并停止；核对没有串消息、乱码或假完成。
- **修复：** 使用协议解析和稳定 run/message ID；增量或批量呈现；区分网络结束与业务完成；清理不可信富文本并约定取消语义。

## C31 长任务进度与运行控制

**适用条件：** 页面管理训练、解析、导出、批处理、Agent 执行或持续运行任务时执行。

- **状态：** 区分排队、启动、执行、待输入、成功、失败、取消中、已取消和状态未知；只在服务端提供时显示真实百分比。
- **动作与反向中断：** 验证刷新、重连、重试、取消和查看日志；在超时后查询任务，在完成与取消同时到达时核对终态。
- **语义键盘：** 给进度和控制提供名称；未知进度用合适不确定状态；让日志暂停、复制和恢复跟随可操作。
- **数据布局：** 检查长任务名、长错误、阶段变化、百分比回退或缺失、日志规模与移动端控制区域。
- **验收：** 创建隔离任务并保留 ID；在提交响应丢失后查询而非盲目重建；刷新并取消，检查最终服务端状态与界面一致。
- **修复：** 使用持久任务 ID、明确状态机和查询恢复；将取消请求与取消确认分开；由服务端保证幂等、权限和版本一致性。

## C32 文件预览下载与导出

**适用条件：** 页面存在文档预览、图片放大、下载链接、报表导出或批量导出时执行。

- **状态：** 覆盖准备、生成、可下载、失败、链接过期和无预览；在大文件中覆盖分段载入或明确限制。
- **动作与反向中断：** 验证预览、翻页、缩放、下载、取消和重新生成；在权限变化或链接过期后重新操作。
- **语义键盘：** 给文档、页面控件和下载入口命名；为无法访问的预览提供适用的等价内容或原文件；避免预览困住焦点。
- **数据布局：** 检查长文件名、不同页面比例、大表格、字体缺失和分页；核对导出范围、时区、单位与界面筛选。
- **验收：** 下载并实际打开隔离样本；比对文件内容和记录数；使临时链接过期，再验证恢复入口及错误反馈。
- **修复：** 区分下载开始、生成完成和文件可用；管理临时资源生命周期；按风险处理表格公式注入、文件名和服务端权限。

## 生成修复条目

对每个确认问题或重要待验证风险填写以下字段，不输出只有“优化体验”的建议：

| 字段 | 填写要求 |
|---|---|
| 定位 | 写明路由、区域、实例标识、共享定义与源码定位 |
| 条件 | 列明角色、数据、视口、输入方式和前置状态 |
| 证据 | 附实际步骤、观察、日志或静态依据，并声明执行范围 |
| 影响 | 描述用户不能完成的动作、错误结果或受影响群体 |
| 机制 | 指明状态、事件、数据契约、语义、布局或资源生命周期根因 |
| 方案 | 给出最小修复边界；需要跨端保证时标明接口或后端依赖 |
| 验收 | 写明正常路径、一个相关反向中断及受影响实例的回归条件 |
| 未决项 | 保留无法确认的依赖、无工具可验证的行为和不适用理由 |

- 对同根因多实例问题合并修复项，但保留完整实例映射和各自复现条件。
- 对无法从当前证据区分的根因列出最小排查动作，不把猜测包装成确定重构范围。
- 对可复用组件缺陷优先修共享定义，对业务契约缺陷明确前后端边界，对纯实例样式问题保持局部修复。

## 官方依据

- 按具体控件选择并核对 [WAI-ARIA APG 组件模式](https://www.w3.org/WAI/ARIA/apg/patterns/)，不要仅添加角色名称而省略行为。
- 用 [WCAG 2.2](https://www.w3.org/TR/WCAG22/) 确认适用成功准则、等级与例外；把 APG 实现指导与完整符合性结论分开。
- 对模态行为核对 [WAI 模态对话框模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。
- 对输入法核对 [MDN KeyboardEvent.isComposing](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/isComposing)，并在目标浏览器上验证事件序列。
- 对日期展示核对 [MDN Intl.DateTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat)；不要把格式化能力当作业务时间模型。
- 对流式协议核对 [MDN 使用 SSE](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events)；只将原生 EventSource 的自动重连行为用于对应实现。
