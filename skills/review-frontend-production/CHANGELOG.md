# 更新记录

- 整理分享包，排除系统元数据与运行缓存。
- 补充证据边界、输出脱敏提醒、许可状态和实际验证记录。

既有审查规则与主要台账结构继续兼容；旧台账未填写 review_depth 时按 full 处理。没有新增自动浏览器审查或生产认证能力。
