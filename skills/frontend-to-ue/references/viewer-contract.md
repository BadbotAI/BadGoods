# 画布与导出约定

`render_map.py` 只把已脱敏模型和静态素材渲染成离线 HTML。它不自动分析业务、不负责脱敏、不运行原始前端。默认使用 HTML；Figma 是明确提出后才执行的独立输出分支。

## 资源

输入目录包含 `ue-spec.json`、`screens/source.css`，以及每屏的 `view` 静态 HTML 和 `capture` 原始 PNG/JPEG/WebP。资源路径必须位于输入目录内。`capture` 应保留原始分辨率；模板将其嵌入单文件，供缩略展示与 PNG 导出共用。

页面截图和静态 DOM 必须对应同一状态与视口。复制表单时读取实际 value、checked、selected，移除过期属性；冻结选中项。页面脚本、事件属性、真实链接与提交动作清除后，再以无脚本 sandbox iframe 展示。只挂载当前聚焦页面的静态 DOM。

## 模型

- ID 唯一、稳定，使用安全 ASCII 字符。页面与关系的目标必须存在。
- `annotation.layout / rules` 是短句数组；关系以 `transitions` 为唯一来源，避免文本与卡片各维护一套逻辑。
- `transition.trigger` 保留控件原名和必要条件；`effect` 描述具体动作；`isReturn` 标识返回，避免把它当作主路径排版依据。
- 可选 `anchorRect` 使用源视口坐标；不可从缩略图坐标直接写入。未测量则省略。
- `viewport` 可按屏覆盖全局值。尺寸必须为有限正数。
- 已有 `map` 坐标不自动覆盖；新增页放在所属模块旁。无坐标时按模块与前向关系布局；循环边不会造成无限递归。人工布局产生的重叠需在视觉复查时处理。

## 输出交互

工具栏用于搜索、模块定位、返回/前进、缩放与导出。选中帧达到可读缩放后出现标注面板；布局、入口、交互按页签阅读。小尺寸时隐藏容易叠加的画布文字，通过提示补全。

流程卡的目标能定位到页面；悬停或键盘聚焦显示边上文字和触发控件轮廓。入口图中来源在前、当前页在后。当前页局部更新保留为本页规则，不画虚假的跨页连线。

键盘、触控取消、异常锚点、窄屏、前进后退与菜单层级均需实际验证。原始业务界面只用于说明；文档浏览动作不得触发原业务写入。

## PNG

页面图保留 capture 原尺寸。UE 图在旁侧根据模型展开全部布局、入口、交互与规则，自动测量中英文换行；高度随标注增长。无外部字体或截图服务依赖。只在完成编码后下载，回收临时 URL；大图超限需给出明确错误。

验证至少涵盖：实际下载、原尺寸像素比对、布局/入口/交互全部出现、不同页签/缩放/浏览器窗口导出一致、长文案不截断、读取失败可恢复。不同浏览器字体和 Canvas 容量可能不同；只报告实际测试过的环境。
