# 页面状态与状态流转

Step 3 建模时读取。每个页面至少过一遍五态；每个关键流程画一遍状态流转。

## 页面五态

| 状态 | 触发条件 | 检查点 |
|---|---|---|
| 理想 | 数据正常、网络正常 | 内容完整、布局正确、操作可用 |
| 空 | 无数据、搜索无结果、首次使用 | 空状态文案、插图、下一步引导、是否保留筛选条件 |
| 加载 | 首次加载、切换、提交、分页 | 骨架/loading/进度、是否禁用重复操作、是否阻塞页面 |
| 错误 | 接口 4xx/5xx、超时、断网、无权限 | 错误文案是否可理解、重试入口、是否保留已有数据 |
| 部分数据 | 部分字段缺失、部分图片失败、部分接口成功 | 缺失字段占位、模块级失败隔离、不整页白屏 |

每种状态都要能回答：用户看到什么、能做什么、怎么恢复。

## 组件状态

| 组件 | 必查状态 |
|---|---|
| 输入框 | 默认、聚焦、已填、校验错误、禁用、只读、加载中 |
| 按钮 | 默认、悬停、按下、聚焦、禁用、加载中、危险态 |
| 列表项 | 默认、悬停、选中、禁用、加载骨架、空占位 |
| 标签页 | 默认、选中、禁用、内容加载中、内容为空 |
| 下拉/选择 | 收起、展开、已选、搜索无结果、多选已选数量 |
| 弹窗 | 打开、关闭中、提交中、提交失败、遮罩不可关闭 |

检查状态之间是否互斥、切换是否正确、视觉是否可区分。

## 流转模板

### 登录

```text
未登录 --打开需登录页--> 跳登录（记录回跳地址）
登录页 --提交正确凭证--> 校验中（按钮禁用）--> 成功 --> 回跳目标页
登录页 --提交错误凭证--> 错误提示（保留账号，密码是否清空）
登录页 --连续失败--> 验证码/锁定
已登录 --刷新--> 保持登录
已登录 --退出--> 未登录（多标签页是否同步）
已登录 --会话过期--> 操作时跳登录 --> 登录后回跳或数据丢失
```

必测非法流转：已登录再访问登录页、退出后按返回键、会话过期后重复提交。

### 表单提交

```text
编辑中 --提交--> 校验失败（聚焦首个错误，保留已填）
编辑中 --提交--> 提交中（按钮禁用，防重复）
提交中 --成功--> 成功提示 + 跳转/清空
提交中 --失败--> 错误提示，保留数据，可重试
提交中 --刷新/返回--> 是否重复提交或丢数据
编辑中 --离开--> 是否有未保存提示
```

### 列表加载

```text
进入页面 --> 加载中（骨架）--> 有数据 / 空状态 / 错误
有数据 --筛选--> 回到第 1 页并重新加载
有数据 --翻页--> 加载中 --> 新一页（滚动位置处理）
有数据 --删除最后一条--> 当前页空 --> 回退上一页或展示空态
错误 --重试--> 加载中 --> 成功/再次错误
加载中 --快速切换筛选--> 旧请求是否覆盖新结果
```

### 一次性/不可逆操作

```text
点击删除 --> 二次确认 --> 提交中 --> 成功移除 / 失败保留
点击支付 --> 确认 --> 支付中 --> 成功页 / 失败可重试
点击发送 --> 发送中 --> 成功 / 失败草稿是否保留
```

重点：重复提交、返回后重试、超时后的真实结果（可能已成功但页面报失败）。

### 验证码 / 短信发送

```text
初始 --输入合法号码并点发送--> 发送中 --> 倒计时（按钮禁用）--> 可重发
初始 --号码不合法点发送--> 提示格式错误，不发送
倒计时中 --刷新页面--> 倒计时是否保留（重置会导致频繁发送）
已发送 --输错验证码--> 错误提示 --多次输错--> 锁定或要求重发
已发送 --验证码过期--> 提示过期，可重发
```

真实发送属于「需授权」，没有测试号时只走查到「点发送之前」。

### 多步骤流程（向导、下单、申请）

```text
第 1 步 --填完下一步--> 第 2 步（第 1 步数据保留）
第 2 步 --上一步--> 第 1 步（已填内容还在）
第 N 步 --刷新/关闭再打开--> 从哪一步继续，数据是否保留
最后一步 --提交失败--> 停留在最后一步，前面数据不丢
任意一步 --直接改 URL 跳到后面的步骤--> 是否被拦截
```

## 状态判定记录

执行状态类用例时记录：

- URL（含查询参数、hash）
- 登录态（Cookie/LocalStorage 是否还在）
- 页面可见内容（截图）
- 关键数据是否保留
- console 报错、失败请求（状态码、响应体）

## 状态模拟方法

先确认当前浏览器工具支持哪些能力（路由拦截、网络节流、离线模式）；不支持的模拟方式，对应用例标「未执行」并写原因，不要用不等价的方法代替。

| 状态 | 首选 | 备选 |
|---|---|---|
| 加载态 | 路由延迟、网络节流 | 慢账号、大数据量账号 |
| 错误态 | 路由返回 500、超时 | 离线模式、无权限账号 |
| 空态 | 新用户账号、搜索不存在的关键词 | 路由返回空列表；都没有则标「不适用」 |
| 部分数据 | 路由拦截部分图片或接口 | 有缺失字段的测试数据 |
| 会话过期 | 清除 Cookie/Token 后再操作 | 修改为过期 Token、等待超时 |
| 多标签页 | 两个标签页同时操作同一数据 | 两个浏览器会话 |

模拟后要用网络记录或页面表现确认「真的进入了该状态」，否则判定无效。
