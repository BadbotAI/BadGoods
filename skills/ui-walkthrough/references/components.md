# 常见组件检查清单

Step 2 拆解页面、Step 4 设计用例时读取。按页面上实际出现的组件取用，不要把所有项都塞进用例。

## 先判断页面类型

| 页面类型 | 走查重点 |
|---|---|
| 表单页 | 校验规则与时机、提交反馈、报错时保留已填内容、防重复提交 |
| 列表页 | 0/1/多条、分页、排序筛选组合、加载失败、数据同步 |
| 详情页 | 与列表数据一致、不存在或无权限的 id、长内容、操作后刷新 |
| 多步骤流程 | 步骤间数据保留、返回上一步、中途离开、最后一步失败 |
| 登录/鉴权页 | 凭证校验、错误次数、登录态保持、未登录拦截、回跳地址 |
| 内容页 | 文案、图片、链接、长内容、窄屏 |

## 输入框

- 空、只有空格、首尾空格、超长、特殊字符、emoji、换行（粘贴）。
- 类型约束：数字、小数位、负数、前导零、科学计数法、金额千分位。
- 最大长度：到上限后还能不能输入、计数器是否准确、粘贴超长是否截断。
- 输入被过滤或截断时，有没有提示（静默清空会让用户以为键盘坏了）。
- 校验时机：失焦校验还是实时校验；实时校验是否在输入过程中频繁报错；直接点提交能否拦住。
- 错误提示：说清错在哪、怎么改；是否清空已填内容；是否聚焦到错误字段。
- 禁用/只读：视觉可区分，不能编辑也不能提交。
- 清除按钮、密码可见切换、中文输入法组合输入。
- 自动填充后值与校验状态是否一致。
- 移动端：键盘类型是否匹配（数字、邮箱），软键盘是否遮挡输入框和提交按钮。

## 按钮

- 默认、悬停、按下、聚焦、禁用、加载中状态是否可区分。
- 快速连点两次是否重复提交；加载中是否禁用并显示进度。
- 点击后按钮文字或状态会变化的（如「加入」变「移除」），连点第二次可能触发相反操作。
- 主按钮、次按钮、危险操作按钮的层级；危险操作是否二次确认。
- 条件不满足时是禁用，还是点击后提示原因；两种都要说得清为什么。
- 键盘 Enter/Space 能否触发；图标按钮是否有可读名称。
- 点击后是否有明确反馈（跳转、提示、状态变化）。

## 选择类控件（下拉、单选、复选、开关、级联）

- 默认值是否合理；必选项未选时的提示。
- 选项很多时是否可搜索；搜索无结果的提示。
- 多选：全选、部分选、全不选；已选数量显示。
- 级联：上级改变后，下级是否清空或重新校验。
- 开关：切换后是否立即生效，失败时是否回滚到原状态。

## 协议与授权勾选

- 默认不勾选；不勾选时能否拦住提交，并提示原因。
- 协议、隐私政策链接能打开，内容完整，可关闭后回到原处。
- 涉及敏感信息（健康、金融、位置）的单独授权是否分开说明。

## 验证码 / 短信

- 发送按钮倒计时、倒计时中禁用、倒计时结束可重发。
- 手机号/邮箱格式不对时不发送。
- 错误验证码、过期验证码、多次输错的提示。
- 刷新页面后倒计时是否重置（可能导致频繁发送）。
- 真实发送短信属于「需授权」操作，执行前先问用户。

## 表单

- 必填项标识、字段分组和顺序是否符合填写逻辑。
- 提交前校验全部字段还是只报第一个错误；错误定位是否清晰。
- 提交成功后：跳转、清空、保留、提示。
- 提交失败后：数据是否保留，是否可重试，重试是否产生重复记录。
- 离开未保存的表单是否提示。
- 刷新/返回后已填内容是否保留（或明确告知不保留）。
- 条件字段：选了某个选项才出现的字段，切换选项后已填值如何处理。

## 列表 / 表格

- 0 条、1 条、多到触发分页或滚动加载；空状态是否有说明和下一步操作。
- 排序：默认排序、切换排序后页码。
- 长文本截断与完整查看（悬浮、展开、详情）。
- 操作列：二次确认、操作后行是否刷新。
- 批量选择：全选、半选、跨页选择，批量操作后的选中状态。
- 加载中骨架或占位；加载失败可重试。
- 横向滚动、固定列、窄屏表现。
- 新增/编辑后列表是否同步，是否需要手动刷新。
- 图片区分「加载失败（404/空白）」与「加载成功但内容错了（如多处复用同一张图）」。

## 搜索与筛选

- 空搜索、只有空格、特殊字符、超长关键词。
- 无结果提示和「清空条件」入口。
- 搜索后页码是否重置；条件是否保留在 URL，刷新后是否还在。
- 连续输入时是否频繁请求；慢请求的旧结果是否覆盖新结果。
- 多个条件组合、清除单个条件、清除全部条件。

## 分页 / 滚动加载

- 第一页「上一页」禁用、最后一页「下一页」禁用。
- 页码跳转：0、负数、超过总页数、非数字；URL 里的页码改成非法值。
- 每页条数切换后页码如何处理。
- 最后一页唯一一条被删除后，停在空页还是回退上一页。
- 总数文案与实际条数一致。
- 滚动加载：到底提示、加载失败重试、快速滚动是否重复加载。

## 导航 / 菜单 / 标签页

- 当前位置高亮是否正确；刷新后是否保持。
- 无权限的菜单是隐藏还是禁用；直接输入其 URL 是否被拦截。
- 标签页切换后内容是否正确，未保存的内容是否提示。
- 面包屑、返回按钮的去向是否符合预期。

## 弹窗 / 抽屉

- 打开后焦点是否进入弹窗，并限制在弹窗内。
- Esc、点遮罩、关闭按钮是否关闭；哪些弹窗不应被遮罩关闭（如有未保存内容）。
- 关闭后焦点是否回到触发按钮。
- 弹窗内表单的校验、提交、失败提示。
- 关闭再打开，上次的输入和错误提示是否残留。
- 嵌套弹窗；打开时底层页面是否锁定滚动。
- 窄屏下内容是否超出屏幕、关闭按钮是否可达。

## 提示 / 通知（Toast、消息条）

- 成功、失败、警告样式可区分，不只靠颜色。
- 停留时间够读完；重要错误不应自动消失。
- 连续触发时是否堆叠、遮挡操作区。

## 上传

- 支持的类型、大小上限、数量上限是否提前告知。
- 超大文件、错误格式、0 字节文件、同名文件。
- 上传进度、取消、失败重试、删除已上传文件。
- 多文件部分成功、部分失败的处理。
- 图片预览；上传后刷新页面，文件是否还在。
- 拖拽上传与点击选择行为一致。

## 下载 / 导出

- 文件名、格式、编码（中文是否乱码）。
- 数据量大时是否有进度或异步通知。
- 导出内容与当前筛选条件一致。

## 日期 / 时间选择

- 手动输入非法日期（2 月 30 日、13 月）；过去/未来日期的限制。
- 跨月、跨年切换；今天、清空等快捷操作。
- 开始时间晚于结束时间的校验。
- 时区、跨天、夏令时；显示格式与本地习惯。
- 移动端选择器是否好用。

## 富文本 / 长文本编辑

- 粘贴带格式内容、图片、表格。
- 超长内容的保存与回显。
- 撤销/重做；离开前未保存提示。
- 保存后回显时 HTML 是否被原样显示或被转义成乱码。

## 登录 / 注册

- 空账号、空密码、错误密码、错误账号、大小写、首尾空格。
- 错误次数限制、账号锁定、验证码刷新。
- 登录成功后跳到哪（原页面或首页）；返回键是否回到登录页。
- 刷新后登录态是否保持；退出后按返回是否还能看到需登录的页面。
- 未登录直接输入需登录页面的 URL 是否被拦截。
- 记住我、自动登录、多标签页退出同步。
- 注册：重复账号、弱密码、两次密码不一致、协议勾选、验证码。
- 会话过期后的操作：跳登录、回跳地址、已填内容是否保留。
- 账号矩阵：正常、新用户、无权限、锁定账号各跑一遍主流程。

## 计数与汇总（购物车、角标、统计数字）

- 角标/汇总数字与实际条目逐条一致；增删后实时同步。
- 切换账号后数据是否隔离；退出后本地数据是否清理。
- 多标签页操作后数字是否同步；刷新后是否正确。
- 金额汇总：小数精度、优惠叠加顺序、为 0 和负数时的显示。

## 移动端通用

- 软键盘弹出时页面是否被顶乱、按钮是否被遮挡。
- 横竖屏切换后布局和已填内容。
- 点击区域是否足够大（约 44×44 以上）。
- 下拉刷新、左滑返回与页面内手势是否冲突。
