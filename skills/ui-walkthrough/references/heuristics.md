# 查漏启发式

Step 4 设计完用例后，用本清单逐条扫一遍，补上遗漏的高价值场景。不要机械套用，只保留适用的。

## 尺寸与数量

| 启发式 | 怎么用 |
|---|---|
| 太大 / 太小 / 刚好 | 文本长度、文件大小、图片尺寸、金额、数量都取上下限和中间值 |
| 0-1-多 | 列表、搜索结果、购物车、标签、附件：0 条、1 条、2 条、多到触发分页/滚动 |
| 部分 / 全部 / 没有 | 批量选择：全选、部分选、全不选；批量删除/导出 |
| 边界刚好跨页 | 总数等于每页条数、每页条数+1，检查分页和序号 |

## 生命周期

| 启发式 | 怎么用 |
|---|---|
| 增删改查 | 每个数据对象走完创建 → 查看 → 编辑 → 删除；检查列表/详情/统计是否同步 |
| 跟着数据走 | 选一条数据，从入口跟到出口：列表 → 详情 → 编辑 → 保存 → 回到列表，检查每步显示是否一致 |
| 重复操作 | 同一操作做两次：创建、提交、收藏、点赞、加入购物车 |
| 撤销 / 恢复 | 删除后能否撤销；取消编辑后原数据是否保留 |
| 排序 / 筛选后 | 排序或筛选后页码是否重置到第 1 页；空结果是否有提示和「清空筛选」 |

## 中断与异常

| 启发式 | 怎么用 |
|---|---|
| 中途离开 | 填到一半点返回、切标签页、关弹窗，数据是否保留或明确提示 |
| 中断 | 上传/提交中断网、刷新、按 ESC，检查提示、重试和数据完整性 |
| 超时 | 接口慢时是否有 loading、骨架屏或超时提示，按钮是否禁用 |
| 失败重试 | 接口失败后重试是否成功，是否产生重复数据 |
| 会话过期 | 停留很久后操作，是否跳登录、是否保留回跳地址和已填内容 |

## 网页导航

| 操作 | 检查点 |
|---|---|
| 返回键 | 返回后页面状态（筛选、页码、滚动位置、弹窗）是否符合预期 |
| 刷新 | 登录态、表单内容、筛选条件、SPA 路由是否保持 |
| 收藏 / 分享链接 | 当前状态的 URL 是否可分享；直接打开是否复现同样内容 |
| 改 URL | 手动改 id、页码、查询参数为不存在/非法值，是否有兜底页而不是白屏 |
| 直接输 URL | 未登录访问后台页面是否被拦截；无权限角色是否被拒 |
| 前进/后退 | 浏览器前进后退与应用内路由是否一致，是否出现重复提交 |
| 新标签页打开 | 链接是否在新标签正常打开，登录态是否共享 |

## 视图与设备

| 启发式 | 怎么用 |
|---|---|
| 窄屏 | 320px / 375px 是否有横向滚动、按钮被遮挡、表格溢出 |
| 放大 | 浏览器缩放 200% 是否可用，文字是否截断 |
| 长内容 | 超长标题、超长用户名、超长错误文案是否换行/省略 |
| 空图/坏图 | 图片 404 是否有占位，头像缺失是否有默认图 |
| 暗色/高对比 | 文字与背景对比是否足够，焦点框是否可见 |

## 输入法与其他

| 启发式 | 怎么用 |
|---|---|
| 输入法 | 中文输入法组合期间是否触发校验或提交 |
| 粘贴 | 粘贴带换行、带格式、超长文本、带前后空格 |
| 自动填充 | 浏览器自动填充后校验状态是否正确 |
| 键盘 | Tab 顺序、Enter 提交、Esc 关闭、方向键选择 |
| 屏幕阅读器语义 | 错误提示是否关联输入框（`aria-describedby`）、图标按钮是否有可读名称 |

## 用户与时间

| 启发式 | 怎么用 |
|---|---|
| 首次 vs 老用户 | 新用户看到的空状态、引导；老用户的大量数据、历史设置 |
| 时间边界 | 跨天、跨月、月底、闰年、时区差、有效期刚好到期 |
| 多语言/地区 | 文案变长是否撑破布局；日期、数字、货币格式 |
| 跟着用户走 | 按真实用户目标走一遍完整任务，而不是只点单个组件 |

## 账号与环境矩阵

- 每个测试账号都是一条数据维度：正常、新用户、大量数据、无权限、锁定/禁用；练习站提供的预设缺陷账号单独一类。
- 每个环境都是一条维度：本地、测试、预发、生产只读；静态托管与动态服务端分开判断。
- 预设缺陷的失败单独统计，不能拉低产品通过率。
